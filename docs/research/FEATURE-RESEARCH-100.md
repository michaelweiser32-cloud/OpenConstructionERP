# Feature Research: 100 Topics for a Small Construction / Estimating Business

**Status:** research only. This document proposes nothing for immediate release, and no application code was changed.
**Scope:** generic construction-ERP features, connectors and MCP integrations for OpenConstructionERP. It uses public sources only.
**Method:** 100 independent research agents ran in 10 waves of 10, each with one topic. For its topic, each agent (1) checked what already exists in this codebase, (2) researched current public sources (official docs, GitHub, pricing pages), and (3) wrote a report in [`topics/`](topics/) covering what it is, who it helps, effort in this codebase, building blocks with links, and a 1–5 priority score.

**Priority distribution:** 13 topics at 5/5, 60 at 4/5, 20 at 3/5, 7 at 2/5, none at 1/5.
**Effort:** almost every topic is Medium. The codebase already has a module (often a partial one) for most areas, so the work is usually closing a gap rather than building from scratch.

**Caveats**
- Scores come from separate agents. Treat them as relative signals, not exact measurements.
- Prices and tier limits change often. One agent (066 LLM providers) explicitly flagged that it could not verify official pricing pages. Re-check prices before you commit.
- Agents were told not to invent APIs. Where something does not exist (for example, a public Levelset API, a public BidNet API, an LCPtracker API, or public RSMeans/BKI/BCIS APIs), the report says so.

Three high-leverage 4/5 topics fill the remaining slots because they are cheap and other items depend on them (notifications, LLM cost reduction, onboarding). ### Notable gaps and bugs the agents found in the existing code

These came out of the "already in the codebase" checks. They are worth verifying and fixing regardless of the roadmap:

- **Regional factor silently dropped:** the frontend sends `regional_factor`, the backend ignores it, and only assemblies apply factors ([003](topics/003-regional-cost-bases.md)).
- **Inconsistent classification crosswalks:** `classification_mapper.py` and `classificationMap.ts` disagree with each other and with DIN 276:2018 / NRM 1 ([009](topics/009-classification-mapping.md)).
- **Markup `per_unit` returns 0** ([006](topics/006-markups.md)).
- **ICS calendar feed** uses weak prefix-only token auth and has RFC 5545 gaps ([050](topics/050-calendar.md)).
- **Offline queue** silently drops 409 conflicts on replay, and there is no service worker or manifest ([081](topics/081-pwa-offline.md)).
- **Reporting:** `generate_report` renders no file and emails nobody ([091](topics/091-dashboards-pdf.md)).
- **Features advertised but missing:** AI symbol auto-detection ([063](topics/063-ai-symbol-detection.md)) and a Procore connector in the marketplace listing ([097](topics/097-procore.md)).
- **Backup** covers about 19 tables and no files ([096](topics/096-backup-portability.md)).
- **Locales:** most are about 69% complete despite the 21-language claim ([093](topics/093-multi-language.md)).
- **EVM overlap:** EVM formulas exist in three overlapping modules ([015](topics/015-earned-value.md)).
- **Unused dependency:** `paddleocr` is declared but not wired in ([061](topics/061-drawing-ocr.md)).

## Connectors + MCP shortlist

Details and module-system wiring are in [MCP-AND-CONNECTORS.md](MCP-AND-CONNECTORS.md).

**Build now (highest value per effort)**
1. **OpenConstructionERP MCP server**: official [Python MCP SDK](https://github.com/modelcontextprotocol/python-sdk) / [FastMCP](https://github.com/jlowin/fastmcp) ([071](topics/071-erp-as-mcp-server.md))
2. **QuickBooks Online**: [python-quickbooks](https://github.com/ej2/python-quickbooks); official [QBO MCP server](https://github.com/intuit/quickbooks-online-mcp-server) ([031](topics/031-quickbooks.md))
3. **Xero**: [xero-python](https://github.com/XeroAPI/xero-python); official [Xero MCP server](https://github.com/XeroAPI/xero-mcp-server) ([032](topics/032-xero.md))
4. **Webhooks + n8n / Activepieces**: Standard Webhooks signing, REST-hook subscribe, [n8n node](https://docs.n8n.io/integrations/creating-nodes/build/declarative-style-node/) ([029](topics/029-automation-webhooks.md))
5. **Cloud drives (one generic layer)**: OneDrive/SharePoint via [Graph delta](https://learn.microsoft.com/graph/api/driveitem-delta), Google Drive (`drive.file` scope), Dropbox, Box ([041](topics/041-google-drive.md)–[044](topics/044-box.md))
6. **Inbound email → RFI/correspondence**: [imap_tools](https://github.com/ikvk/imap_tools) first, then Gmail push / Graph notifications ([046](topics/046-email-integration.md))
7. **E-signature**: self-hosted [DocuSeal](https://github.com/docusealco/docuseal) / [Documenso](https://github.com/documenso/documenso), or [DocuSign MCP](https://developers.docusign.com/platform/mcp-server) ([051](topics/051-e-signature.md))
8. **Client payments**: Stripe ACH/SEPA payment links, [Stripe MCP](https://docs.stripe.com/mcp), [Mollie MCP](https://docs.mollie.com/docs/mollie-mcp-server) ([034](topics/034-client-payments.md))
9. **Slack/Teams approvals + WhatsApp/Telegram field bots**: wire the existing send-only connectors to the event bus and add inbound webhooks ([048](topics/048-whatsapp-telegram.md), [049](topics/049-slack-teams.md))
10. **Free public data**: [Open-Meteo](https://open-meteo.com/en/pricing) weather, [BLS](https://www.bls.gov/developers/)/[FRED](https://fred.stlouisfed.org/)/[Destatis](https://www.destatis.de/EN/Service/OpenData/api-webservice.html) price indices, [SAM.gov](https://open.gsa.gov/api/get-opportunities-public-api/)/[TED](https://docs.ted.europa.eu/api/latest/index.html) tenders ([083](topics/083-weather.md), [024](topics/024-price-feeds.md), [090](topics/090-bid-boards.md))

**Build next (after an MCP client exists in `erp_chat`, [080](topics/080-mcp-client-architecture.md))**
- Communication MCPs ([Slack MCP](https://docs.slack.dev/ai/mcp-server/), [Twilio MCP](https://github.com/twilio-labs/mcp)) ([079](topics/079-communication-mcp.md))
- Web-search MCP for price/datasheet lookups, with human review ([Tavily](https://github.com/tavily-ai/tavily-mcp), [Brave](https://github.com/brave/brave-search-mcp-server)) ([076](topics/076-web-search-mcp.md))
- Google Workspace MCP (Google-hosted servers are still in developer preview) ([075](topics/075-google-workspace-mcp.md))
- Read-only database MCP for analytics ([Postgres MCP Pro](https://github.com/crystaldba/postgres-mcp), [DBHub](https://github.com/bytebase/dbhub)) using a SELECT-only role ([074](topics/074-database-mcp.md))

**Defer / low priority for small firms:** Procore ([097](topics/097-procore.md)), Autodesk Build/APS ([098](topics/098-autodesk-aps.md); its official MCP server was archived), Bluebeam Studio API (file import of Revu markups first, [099](topics/099-bluebeam.md)), payroll connectors ([038](topics/038-payroll-connectors.md)), browser-automation MCP ([077](topics/077-browser-mcp.md)), filesystem and GitHub MCP ([072](topics/072-filesystem-mcp.md), [073](topics/073-github-mcp.md)).
